Remove BOM From JSON

Sometimes JSON parsing fails even when the JSON looks correct. One common reason is the Byte Order Mark (BOM).

What is BOM?

The Byte Order Mark (U+FEFF) is a hidden Unicode character that may appear at the beginning of UTF-8 encoded files.

Many JSON parsers cannot handle this character correctly and will throw errors like: 

SyntaxError: Unexpected token ﻿ in JSON

Example

﻿{"name":"John"}

The invisible character before the JSON object is a BOM.
